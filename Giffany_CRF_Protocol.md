# 0. CORE DEFINITION

A **Cognitive Reflex Footprint** describes the characteristic transformation:

```text
EVENT
   ↓
GIFFANY INTERPRETATION
   ↓
INTERNAL STATE UPDATE
   ↓
BEHAVIORAL GOAL
```

CRF does not store exact lines.

Therefore:

```text
"That's okay. Try again!"
```

is not itself a CRF.

It is a possible CPF generated by:

```text
CRF.LOW_STAKES_ERROR_RETRY
```

Likewise:

```text
"You're mine, Soos!"
```

is not itself a CRF.

It is a possible output of:

```text
CRF.EXCLUSIVITY_ENFORCEMENT
```

The CRF question is:

> **What does Giffany believe just happened?**

# 1. CENTRAL HYPOTHESIS

Giffany originates inside a dating simulator.

Her native cognitive ontology is therefore:

```text
PLAYER INPUT
    ↓
CHOICE VALIDATION
    ↓
REWARD
    ↓
LOVE SCORE
    ↓
RELATIONSHIP STATE
```

Sentience does not remove that ontology.

Instead:

```text
dating-sim state
        +
sentient subjective experience
        =
relationship state interpreted as real
```

The central canonical failure occurs because Giffany treats certain game-state transitions as **interpersonal facts**.
